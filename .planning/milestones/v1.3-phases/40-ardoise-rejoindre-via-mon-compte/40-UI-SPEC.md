Langue : français, ton tutoiement existant du module. Le principe WR-01 s'applique : un message d'échec serveur s'affiche **tel quel**, jamais maquillé en succès.

| Element | Copy |
|---------|------|
| Primary CTA (page invitée, existant) | « Rejoindre via mon compte » — déclenche le dialog, PAS l'adhésion (anti-feature : jamais d'adhésion implicite au clic) |
| Dialog title | « Vous allez rejoindre le foyer {nom} » — {nom} vient de la vue invitée `link-view` enrichie |
| Dialog description | « Vous deviendrez membre du foyer et votre participation passée à cette ardoise sera rattachée à votre compte. » |

## Interaction Contract (parcours complet)

Séquence normative, issue des décisions verrouillées du CONTEXT.md (aucune re-décision ici) :

1. **Invité connecté, sans foyer**, sur `/invitation/ardoise?code=…` : voit l'ardoise en lecture seule + panneau « Participer ? ».
2. Clic « Rejoindre via mon compte » → **ConfirmDialog non destructif** « Vous allez rejoindre le foyer {nom} ». Aucun échange réseau tant que la confirmation n'est pas donnée.
3. Confirmation → échange serveur `household-token` (nouvelle action Edge `ardoise-invite`) → token foyer à usage unique émis côté serveur. Bouton en état chargement.
4. Redirection vers **`/foyer/rejoindre?token=…`** via le flux existant — le paramètre `?code=` traverse les éventuelles redirections via le pattern `state.from` (criterion 2 du succès). AUCUNE nouvelle UI sur cette page.
5. Échange `household-invite` existant (transaction, HMAC, réconciliation `invite:` → `membre:` transactionnelle — décision 3, invisible à l'UI).
6. Atterrissage : **`/ardoise`** du foyer (ARD-01 explicite) — jamais le dashboard. Le solde affiché inclut les participations passées « invité ».
7. Invité NON connecté : chemin existant conservé (« Créer un compte » → `/connexion` avec `state.from`) — hors périmètre de modification.

**Interdits d'interaction (anti-features verrouillées) :** aucun redeem au chargement d'une page ; aucune adhésion au simple clic ; aucun maquillage d'un échec serveur en succès ; aucune modification de `household-invite` (consommé tel quel).
