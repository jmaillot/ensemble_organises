# Phase 29 — UI Design Contract

> Visual and interaction contract for the Messagerie v2 phase. Generated by gsd-ui-researcher from 29-CONTEXT.md, REQUIREMENTS.md (MSG-01…MSG-05) and the approved 25-UI-SPEC. Verified by gsd-ui-checker.

**Surfaces touchées (décisions D-01 à D-09) :**
1. `conversation-list.tsx` : badges non-lus alimentés par le watermark serveur (MSG-02), entrée « démarrer une directe » via le member-picker (MSG-01, D-04).
2. `chat-panel.tsx` : accusés de lecture sous le dernier message envoyé (MSG-03, D-02) ; watermark écrit à l'ouverture du fil (D-01) ; rafraîchissement Realtime fil + liste (MSG-05, D-08).
3. Notification push groupée : compteur « N nouveaux messages de {conversation} », jamais le contenu (MSG-04, D-06/D-07).
4. Migration silencieuse du localStorage vers le serveur au premier chargement (D-03) — invisible à l'écran, aucune UI dédiée.

## Color

Charte existante (`app/src/styles/app.css`) — aucun nouveau token :

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-bg` `#f2f0ec` | Fond de page, aplat liste |
| Secondary (30%) | `--color-surface` `#ffffff` | Cartes conversation, Panel, Dialog, bulles du fil |
| Accent (10%) | `--color-accent` `#20413d` | CTA primaires, conversation sélectionnée, focus (`outline 3px --color-accent-strong`) |
| Destructive | `--color-coral` `#d95f5c` (+ `coral-soft`) | Hors périmètre de cette phase (aucune action destructrice nouvelle) |

Accent réservé à : bouton de confirmation du picker de démarrage, état sélectionné d'une conversation dans la liste, focus-visible. **Jamais** pour les badges non-lus ni les accusés.

Sémantique spécifique à la phase :
- **Badge non-lu (MSG-02)** : reprend le gabarit `CountBadge` existant de la liste (accent actuel de la liste, non nuancé) — le watermark change la source de vérité, pas le visuel. Le badge disparaît quand `last_read_at >= dernier message` (D-01 : ressaisi à l'ouverture du fil, et au retour sur l'onglet).
- **Accusés de lecture (D-02)** : avatars `MemberAvatar sm` sur `color_tag` du membre + horodatage `text-muted`. Un membre qui n'a pas lu n'apparaît pas (absence, jamais un avatar grisé — pas de nouvel état visuel). Les variantes `*-deep` restent obligatoires sous initiale blanche.
- Les notifications push (D-06) sont hors DOM : copie ci-dessous, aucune couleur.

## Copywriting Contract

Tous les libellés en français, ton existant (tutoiement, phrases courtes, jamais de vocabulaire technique — « watermark », « RPC », « Realtime » interdits à l'écran) :

| Element | Copy |
|---------|------|
| Primary CTA (démarrer une directe) | **« Démarrer une conversation »** — bouton de la liste vide ET du panneau de liste, icône `people`, ouvre le member-picker (D-04) |
| Picker (D-04) | Titre : « À qui écrire ? » — tap sur une ligne membre = démarrage ou réouverture immédiate de la directe (D-05), sans bouton « créer » intermédiaire. Case « un tap, un résultat » : le membre déjà en directe rouvre le fil existant |
| Titre de conversation directe | Prénom(s) du ou des autres membres (gabarit existant de `conversation-list`), jamais « Conversation directe » ni « privée » |
| Empty state (liste) | Heading : **« Aucune conversation »** — Body : « Écrivez à un membre du foyer en un tap. » + bouton « Démarrer une conversation » |
| Empty state (fil ouvert sans message) | Heading : « Rien pour l'instant » — Body : « Envoyez le premier message à {prénom}. » |
| Badge non-lu | Nombre seul, jamais « nouveau » ni « non-lu » (gabarit CountBadge) |
| Accusé de lecture (D-02) | Rangée d'avatars + horodatage ; sans libellé. En l'absence totale de lecteurs, la rangée ne s'affiche pas (pas de « Vu par personne ») |
| Loading (démarrage de directe) | Ligne membre du picker : spinner inline + libellé inchangé (jamais un bouton « Connexion… ») |
| Error (échec RPC démarrage) | Toast erreur : « Impossible d'ouvrir la conversation. Réessayez. » — le message serveur lisible prime s'il existe |
| Error (échec envoi message) | Pattern existant du chat-panel inchangé |
| Notification push groupée (MSG-04, D-06) | Titre : **« {prénom du dernier expéditeur} »** — Corps : **« {N} nouveaux messages dans {titre de conversation} »** (singulier : « 1 nouveau message »). Jamais d'aperçu, d'extrait ou de contenu du message — verrouillé. `tag` OS = conversation (existant 0042), le compteur est cumulatif au cycle dispatch (D-07 : pas de « première immédiate ») |
| Migration localStorage (D-03) | **Aucune UI.** Portage au premier chargement, retrait de la clé après confirmation serveur ; en cas d'échec du portage, dégradation silencieuse vers l'état actuel (badges 1/0), jamais un message d'erreur visible pour une migration technique |
