Fonction `private.purge_expired_account_deletions()` — `language plpgsql volatile security definer set search_path = ''`, exécutée par pg_cron en service_role, **zéro HTTP** (RGDP-04). Pour chaque demande `status in ('demandee','rappellee') and purge_due_at <= now()`, DANS UNE TRANSACTION par demande :

1. **Règle enfant (D-08)** : pour chaque profil enfant (lignes `household_members` sans `user_id` avec `deleted_at is null`) du/des foyers où l'ancien compte était adulte — si d'autres adultes restent dans le foyer : réattribuer la gestion aux adultes restants sur le motif `link_managed_child` (0149 — réattribution transactionnelle, JAMAIS de DELETE brut, cascades 0150) ; si l'ancien compte était l'unique adulte : les profils enfants sont purgés avec le compte.
2. **Foyer orphelin (D-09)** : si aucun adulte ne reste dans un foyer dont l'ancien compte était membre — appeler la logique de `public.delete_household` (0074, dépenses d'abord, cascades ensuite) : réutiliser la fonction existante, ne pas la copier.
3. **Manifest médias (D-07)** : AVANT toute suppression, insérer dans une table `private.account_deletion_media_manifest` (créée dans la même migration : `id uuid pk`, `household_id uuid`, `storage_path text`, `purged boolean not null default false`, `created_at timestamptz default now()`) les chemins `storage.objects` du ou des foyers concernés (`name like '<household_id>/%'`). Les foyers NON orphelins ne génèrent AUCUNE ligne : leurs médias restent (D-07).
4. **Purge du compte** : `delete from auth.users where id = <user_id>` (précédent 0145:143) — les cascades désormais auditées (0166) ne peuvent plus toucher les données partagées ; mettre `status = 'purgee'` sur la demande et purger la ligne d'instantané (la restauration n'est plus possible après J+30).
5. Retourner un jsonb de contrat honnête : nombre de demandes purgées, enfants transférés/purgés, foyers supprimés, lignes de manifest posées.

`grant execute … to service_role` uniquement (revoke public, anon, authenticated). Le flag `rappel_envoye` n'est PAS touché ici (c'est le rôle du J-7).
