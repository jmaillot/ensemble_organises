# Phase 25 — UI Design Contract

> Visual and interaction contract for the child-profile phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Surfaces touchées (décisions D-02, D-10 à D-14, D-21, D-12) :**
1. `members-panel.tsx` étendu : création / édition / suppression des profils enfants (D-02), fiche enrichie (D-05), bouton « Donner accès » (D-21).
2. Sélecteurs de membres (tâches, routines) : attribuer / cocher « au nom de » un enfant (D-10, D-11) ; l'attributaire seul est affiché (D-14).
3. Sélecteurs des autres espaces : l'enfant n'y est attribuable que si le module est activé sur sa fiche (D-06) — option désactivée sinon.
4. Cercle : modération des contenus attribués à un profil enfant (D-12) — jamais de publication au nom de l'enfant.

## Spacing Scale

Declared values (multiples of 4, alignées sur les utilitaires Tailwind déjà employés) :

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gaps d'icônes (`gap-1`), micro-espacements |
| sm | 8px | `gap-2` / `gap-1.5` des lignes d'actions du members-panel |
| md | 12px | `gap-3` lignes de membres, rayons `rounded-[14px]` avatars lg |
| lg | 16px | `gap-4` / `py-3` entre lignes de liste |
| xl | 24px | Padding interne des Dialog, section fiche |
| 2xl | 32px | `mt-4 mb-0` notices + marges de blocs dans les panneaux |
| 3xl | 48px | Séparation entre panneaux de la page Paramètres |

Exceptions :
- `--spacing-gutter: 38px` — gouttière de mise en page existante, ne pas retoucher.
- Tailles d'avatar fixes 23/32/44px (`sm`/`md`/`lg` de `MemberAvatar`) — l'enfant réutilise ces gabarits, la cible tactile ≥ 44px est assurée par les `Button size="sm"` avec padding, conformément aux guidelines §6 d'AGENTS.md.
- Badges `min-h-6` (24px) — gabarit existant, inchangé.

## Typography

La charte existante prime (`app/src/styles/app.css`) ; la phase n'introduit aucune nouvelle taille.

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body | 15.5px | 400 | 1.45 | Inter Tight Variable |
| Dense (lignes de liste, champ de saisie) | 13px | 400 | 1.45 | Inter Tight Variable (`text-[13px]`, gabarit members-panel) |
| Micro-label / Badge / eyebrow | 11px | 800 | 1.2 | Inter Tight (`text-[11px] font-extrabold`, utilitaires `eyebrow`/`section-kicker`) |
| Heading (titres de Dialog / SectionHeading) | 22px | 400 | 1.2 | Fraunces Variable (serif, `letter-spacing: -0.022em`) |

Weights déclarés : **400** (corps, titres serif) et **800** (badges, eyebrows, libellés de boutons à forte hiérarchie) — seuls poids utilisés dans les surfaces de cette phase.

L'**âge calculé** (D-05) s'affiche en `text-[11px] text-muted` à côté de la date de naissance : format « 8 ans » (ou « 2 ans, 3 mois » sous 3 ans ; « 10 mois » avant 1 an) — même gabarit que la ligne couleur/rôle du members-panel.

## Color

Charte existante (`app/src/styles/app.css`) — aucun nouveau token :

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-bg` `#f2f0ec` | Fond de page, aplats de panneaux |
| Secondary (30%) | `--color-surface` `#ffffff` | Cartes, Panel, Dialog |
| Accent (10%) | `--color-accent` `#20413d` | CTA primaires, états sélectionnés, focus (`outline 3px --color-accent-strong`) |
| Destructive | `--color-coral` `#d95f5c` (+ `coral-soft #f8e3e1` / `coral-text`) | Suppression de profil, modération, hover destructeur |

Accent réservé à : boutons primaires des Dialog (créer/enregistrer la fiche, « Donner accès »), Checkbox cochées des restrictions par module, focus-visible, avatar `color_tag: accent`. **Jamais** pour signaler le statut enfant.

Sémantique spécifique à la phase :
- **Ambre** (`--color-amber-soft` `#f7ebd3` + `amber-strong oklch(52% 0.11 78)`) : le seul marqueur visuel du statut « enfant » (Badge `tone="amber"`, classe `roleToneClass.enfant` existante). Un profil géré ne se distingue **que** par ce badge + son `color_tag` — pas d'icône supplémentaire.
- Les variantes `*-deep` (coral-deep, amber-deep) sont obligatoires sous toute initiale blanche d'avatar (contraste AA, critique du 24/10/2026 documenté dans `member-avatar.tsx`).
- `--color-ink-soft` / `--color-on-dark` : réservés aux surfaces sombres existantes, hors périmètre.

## Copywriting Contract

Tous les libellés en français, ton existant (tutoiement, phrases courtes, jamais de valeur SQL à l'écran) :

| Element | Copy |
|---------|------|
| Primary CTA (création) | **« Ajouter un enfant »** — bouton du members-panel, visible par tout adulte (D-01), icône `people` |
| Primary CTA (liaison) | **« Donner accès »** — bouton de la fiche enfant (D-21), ouvre l'invitation standard du foyer |
| CTA « au nom de » (tâches) | **« Assigner à »** + picker membres — l'enfant y figure comme n'importe quel membre ; case cochée = l'enfant est attributaire (D-10, D-14) |
| CTA « au nom de » (routines) | **« Cocher pour »** via le même picker ; la complétion s'affiche au nom de l'enfant seul |
| Fiche — champ restrictions | Groupe « Espaces où il peut figurer » : cases des modules du socle **Tâches, Routines, Anniversaires, Menu** pré-cochées (D-06) ; case désactivée = « Il ne peut pas encore figurer dans cet espace. Activez-le ici pour qu'il soit attribuable. » |
| Empty state heading | **« Aucun profil enfant »** |
| Empty state body | « Les enfants du foyer apparaissent dans les listes sans avoir besoin de compte. Créez une fiche pour chacun. » + bouton « Ajouter un enfant » |
| Error state (formulaire fiche) | Reprise du message d'erreur serveur via `Field error` (pattern renommage) ; fallback : « Enregistrement impossible. Réessayez. » |
| Error state (mutation picker/routine) | Toast erreur : message serveur si lisible, sinon « L'opération n'a pas abouti. Réessayez. » |
| Destructive confirmation (suppression profil) | Titre : « Supprimer la fiche de {prénom} ? » — Corps : « La fiche disparaît des listes et des sélecteurs. Les tâches passées et les complétions restent dans l'historique, attribuées à {prénom}. » — Confirm : « Supprimer la fiche » (D-04 : traces conservées, jamais de purge) |
| Destructive confirmation (modération Cercle) | Titre : « Supprimer ce contenu de {prénom} ? » — Corps : « Ce contenu ne sera plus visible dans le Cercle. » — Confirm : « Supprimer » (D-12 ; même gabarit que les ConfirmDialog Cercle existants) |
| Notice statut géré | « {prénom} n'a pas de compte : un adulte agit pour lui, ici et dans les listes. » — notice `bg-bg text-[12px] text-muted` sous la liste (pattern `roleChangeNotice`) |
| Toast post-création | « La fiche de {prénom} est créée. » |
| Toast post-suppression | « La fiche de {prénom} est supprimée. Ses traces restent dans l'historique. » |
| Post-liaison (D-19/D-20) | Toast : « {prénom} a désormais son propre accès. Tout son historique suit. » |

Interdits : « profil géré », « acteur », `actor_member_id` ou tout vocabulaire technique à l'écran ; l'acteur parent n'est **jamais** affiché (D-14). Le Cercle n'offre **aucun** bouton « publier au nom de » (D-12).
